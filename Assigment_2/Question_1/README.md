# Problem Set 2 — Question 1 code

All returns are **monthly, in percent**. The risk-free rate is the sample mean
of the spreadsheet's risk-free column (0.2701 %/mo ≈ 3.24 %/yr). Short sales
are unrestricted, so every portfolio has a closed form — no optimizer is used
in Question 1.

| file | what it does |
|---|---|

Run everything:


Outputs land in `tables/` (csv) and `figs/` (png, 200 dpi).

## Note for whoever does Question 3

Do **not** rewrite the bootstrap. Step 3 must reproduce 1(e) exactly for the
comparison to be valid. Import it:

```python
import data_load as dl, simulate as sim
d = dl.load()

def rule_lw_mvp(R_sim, rf):                 # your robust rule goes here
    from sklearn.covariance import LedoitWolf
    return dl.mvp_weights(LedoitWolf().fit(R_sim).covariance_)

res = sim.run(sim.make_bootstrap_sampler(d["R"]),
              {"Tangency": sim.rule_tangency, "Robust": rule_lw_mvp},
              d["mu"], d["Sigma"], d["rf"], n_sims=1000, seed=20260918)
```

Use the same `seed=20260918` as 1(e) so the two sets of bootstrap draws are
identical and the comparison is paired. `sim.dispersion(...)` returns the
metrics Step 3 asks for (cross-simulation SD of weights, SD of realized means,
SD of realized volatilities). The 1(e) tangency weights are also cached in
`tables/q1e_bootstrap_weights.npz`.

The baseline tangency weights from 1(a) are in `tables/q1a_summary_stats.csv`.
